# GAME HUB

Структура:

- `index.html` — только разметка страницы
- `css/` — стили по частям: base, header, hero, cards, footer, effects, filter, responsive
- `js/` — скрипты: data (список жанров и настройки), games (карточки и страницы), filter (фильтр жанров), effects (эффекты и счётчики), header (шапка и меню)
- `assets/images/` — сюда класть картинки

Порядок подключения CSS и JS в `index.html` важен, не меняй его.
