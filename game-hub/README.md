# GAME HUB

Структура:

- `index.html` — только разметка страницы
- `css/` — стили по частям: base, header, hero, cards, footer, effects, filter, responsive, theme (светлая тема и кнопка)
- `functions/api/stats.js` — серверная часть общих счётчиков (только для Cloudflare Pages, см. ниже)
- `js/` — скрипты (counters — счётчики): data (список жанров и настройки), games (карточки и страницы), filter (фильтр жанров), effects (эффекты и счётчики), header (шапка и меню), theme (переключатель день/ночь)
- `assets/images/` — сюда класть картинки

Порядок подключения CSS и JS в `index.html` важен, не меняй его.

## Как добавить свои игры

Открой `js/data.js`, найди массив `GAMES` и замени его своим списком в таком формате:

    {id:1, title:'Название', cover:'assets/images/1.jpg', genre:'vn', tags:['2D','Комедия'],
     views:21300, downloads:4505, likes:47, date:'2026-10-30', size:'296MB', url:'game.html', h:210}

- `genre` — id жанра из списка `GENRES` (в том же файле), `tags` — теги из этого жанра
- `cover` — путь к картинке-обложке (пусто = цветная заглушка)
- метка NEW ставится сама, если игре меньше 7 дней

## Общие счётчики (просмотры, лайки, загрузки)

Без настройки счётчики работают «в режиме браузера»: лайк и просмотр видит только тот, кто их поставил.
Чтобы числа были общими для всех посетителей, подключи бесплатную базу Cloudflare D1
(сайт должен быть подключён к Cloudflare Pages через репозиторий GitHub):

1. Cloudflare → Storage & Databases → D1 → Create database (имя любое, например `gamehub`).
2. Pages → твой проект → Settings → Bindings (или Functions) → Add → D1 database.
   Имя переменной (Variable name) строго `DB`, база — созданная в шаге 1. Сохрани.
3. Сделай новый деплой (залей изменения в GitHub). Таблица создастся сама.

Проверка: открой `https://твой-сайт/api/stats` — должно показать `{}` (пусто) или числа.
Если там ошибка или страница сайта — база не подключена, и сайт спокойно работает в режиме браузера.

Загрузки: когда сделаешь кнопку «Скачать», вызывай при клике `Stats.download(id)`.
