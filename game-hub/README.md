# GAME HUB

Структура:

- `index.html` — только разметка страницы
- `css/` — стили по частям: base, header, hero, cards, footer, effects, filter, responsive, theme (светлая тема и кнопка)
- `js/` — скрипты: data (список жанров и настройки), games (карточки и страницы), filter (фильтр жанров), effects (эффекты и счётчики), header (шапка и меню), theme (переключатель день/ночь)
- `assets/images/` — сюда класть картинки

Порядок подключения CSS и JS в `index.html` важен, не меняй его.

## Как добавить свои игры

Открой `js/data.js`, найди массив `GAMES` и замени его своим списком в таком формате:

    {id:1, title:'Название', cover:'assets/images/1.jpg', genre:'vn', tags:['2D','Комедия'],
     downloads:4505, likes:47, date:'2026-10-30', size:'296MB', url:'game.html', h:210}

- `genre` — id жанра из списка `GENRES` (в том же файле), `tags` — теги из этого жанра
- `cover` — путь к картинке-обложке (пусто = цветная заглушка)
- метка NEW ставится сама, если игре меньше 7 дней
